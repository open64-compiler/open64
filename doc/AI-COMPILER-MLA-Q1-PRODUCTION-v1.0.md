# Q1 production routing and PREOPT fact rebinding v1.0

November 10, 2026. Supplements [Q1 common High and owned facts v1.0](AI-COMPILER-MLA-Q1-HIGH-OWNED-FACTS-v1.0.md) and [implementation plan v1.16](AI-COMPILER-OPTIMIZATION-SEARCH-IMPLEMENTATION-PLAN-v1.16.md). Earlier specifications, source contracts and retained receipts remain historical evidence.

## Delivered behavior and entry ABI

The normal `be` driver can consume the genuine quantized/paged source `.B` and automatically construct common High WHIRL. No `q1-prepare` / `q1-high` process or external recipe is required. Enable the explicitly versioned standalone entry ABI with:

```text
-DSL:q1_high=buffer-v1
-OPT:IEEE_arith=1:roundoff=0
```

This is an ABI opt-in, not model-name recognition. The original source function symbol becomes a void function with one restrict pointer per owned storage root, in detached value order, followed by a disjoint int32 status pointer. The caller supplies every input, output and intermediate buffer at the prescribed static extent and encoding. All buffers, including status, are mutually disjoint. Reshape values alias their storage root. Input buffers remain immutable. Status 0 means success; status 1 means reject the input, and the caller must discard all results and partial scratch. The compiler does not insert a serving fallback call or publish a cache update. The standalone inspector can reconstruct the buffer manifest from the independently reopened output image:

```text
tensor_kernel_lower q1-production-manifest output.N manifest.json
```

The source tensor-carrier ABI cannot be silently changed for arbitrary callers. This implementation admits only a single top-level entry, with no child PU, call-image callsite records or existing auxiliary PU state. It rejects IPA, distributed/autoparallel, DSL WOPT, conflicting FHE/normalization/CUDA checkpoint routes and pre-VHO profiling/instrumentation modes. The closed source census rejects calls, unsupported operators, contradictory traits and unproved scale joins. Fast math, reassociation-permitting roundoff or an IEEE mode other than IEEE_ACCURATE refuse before construction. Here the numeric IEEE option is **1**; 3 means IEEE_ANY and does not satisfy this contract.

Default/unset and `q1_high=off` retain ordinary backend routing. An unsupported ABI, source or scope likewise returns to that route before executable WHIRL or the ABI changes. Ordinary fallback may still reject a marker-only source schema, exactly as before; refusal is not a claim that the old backend can execute the new source representation. After semantic lowering commits, unavailable analysis facts leave the already lowered algorithm on ordinary compilation; they never restore a source ABI with incompatible callers. Unexpected invariant, allocation or checkpoint-publication failures after commit are compilation failures, not a partially transformed fallback.

## Concrete backend phase order

1. Read global native image records and initialize special global symbols. Check ABI option, file/PU scope, strict numeric context, auxiliary records and checkpoint destinations. The driver loads and owns this one local scope, captures the detached semantic program with the native source service, saves its resident scope using the established Save/Restore protocol, and restores global context. No frontend builder, Python or JsonCpp enters `be.so`.
2. Select ordinary terminal writer versus the existing standard-only writer. Source-only DSL interface records remain in process; no managed table is reset. For the admitted physical ABI, standard-only terminal output omits the obsolete abstract source interfaces. No opcode, WN/ST/TY binary layout, reader format or global source schema meaning changes.
3. During ordinary per-PU setup, restore the resident scope. Immediately before semantic materialization, optionally snapshot the original source with its ordinary interfaces. Replace only this entry with a fresh empty entry preserving its function symbol, then use the existing Q1 High builder. Check no native domain operator remains. Snapshot the completed High through the standard writer. This is mandatory semantic expansion even at O0, not a search-selected optimization.
4. Run ordinary VHO and region/optimization-level setup. Common High uses signed DO_LOOP and OPR_ARRAY, source-order F32 folds, byte storage with promoted arithmetic, guarded page/index operations and fresh functional scatter. Existing backend phase switches still control PREOPT/LNO/WOPT. Q1 does not invoke the MLA candidate materializer.
5. Immediately before real whole-function PREOPT in LNO, create the Q1 PREOPT session from persistent metadata, optionally snapshot the actual input root, capture current source-form facts, then invalidate its epoch before calling the optimizer. A subsequent proactive PREOPT invocation invalidates again and gets a distinct snapshot ordinal. Driver PREOPT-only processing uses the same lifecycle.
6. Install PREOPT's returned whole-function root in the owning PU. Repeat persistent source/key validation, restore explanatory COMMENTs, then read only the actual returned native sites. LNO supplies its live DU manager through a synchronous callback for unique scalar address definitions; the provider never retains the manager. It captures new owned facts under the new epoch, recaptures to verify them, and checks executable identity and ST/TY counts remained unchanged during observation. Snapshot after annotation/rebinding. Annotation and snapshots are outside search.
7. Invalidate the fresh facts before the next optimizer mutation (LNO or subsequent backend phase), and close the epoch when the session leaves scope. Native managers/pools remain owned by their existing phase. Ordinary later structured memory lowering, mapping and code generation continue; this milestone adds no quantized GPU candidate, GPU layout or TMA lowering.

Optional review output uses `-DSL:q1_checkpoint=/absolute/fresh/prefix`:

| Image | Boundary |
| --- | --- |
| `prefix.source.before.B` | Original source immediately before semantic construction |
| `prefix.high.after.B` | Completed standard common High |
| `prefix.preopt-N.before.B` | Actual input immediately before each PREOPT invocation |
| `prefix.preopt-N.after.B` | Actual returned root, with Q1 explanation annotation and fresh observation |

Checkpointing uses a forked writer so the parent writer/context remains intact, plus no-replace publication. It is optional and separate from estimation. Never overwrite retained receipts. Reopen each B independently using `ir_b2a -st -src` and retain full `.T` files and raw diffs. Give whirl2c a distinct `-ft,...phase.t`: a default `.t` can overwrite `.T` on a case-insensitive host. The PREOPT-only `.P` output is retained as-is; the test copies it byte-for-byte to `.B` for the existing whirl2c suffix parser.

## Persistent operation joins and owned facts

The Q1 producer binds `tensor.q1.algorithm` on the function ST. It is a bounded canonical `open64.q1.algorithm.v1` record of all detached values, source positions, operators, versions, attributes, storage/reshape identities, inferred content roles, encoding, evidence and scale SSA associations. The existing complete `tensor.high.recipe_key` seals it. Parsing requires exact fields/types, valid encoding, canonical serialization, bounded values/rank/strings and repeat detached admission. Malformed, duplicated, extra or stale metadata is refused. Header-only RapidJSON is serialization infrastructure, not a new backend shared-library dependency.

Each Q1 operation has distinct induction declarations carrying `tensor.q1.operation`. PREOPT may retain, clone, narrow or eliminate loops. Rebinding traverses actual native memory sites and surviving loop declarations; it does not reconstruct a source schedule by reading COMMENT text. Unknown/eliminated operation grouping is recorded explicitly. A malformed retained tag refuses the observation. Every owned access records actual lexical identity, storage/formal resolution, source-local version, group or unknown group, loop nest, memory encoding/width, address expression, read/write, conditionality and indirectness. Storage facts include shape/strides/payload, source cache/scale pairs, origin, returned-copy lineage and current-invocation lexical endpoints. Source versions are provenance labels, not claims that PREOPT emits precisely the source operation sequence.

Canonical rebinding tolerates PREOPT's I4/I8 zero-based unit loops with LT/LE tests and actual scalarized addresses. A base hidden in a temporary is recovered only from a complete unique live DU definition; ambiguous, incomplete, recursive or absent resolution refuses the provider. A load-derived or uncertain scalar index stays indirect. Non-ARRAY memory remains conservatively indirect. Unrecognized loop/memory forms or unsupported exact native identities refuse analysis while ordinary compilation proceeds. No code normalization is performed by the observer.

Freshness has two parts: the existing epoch activation/generation token and exact native/source/observed-join identity. Changed numeric context, source/scale metadata, pointer restrict contract, native expression, operation join or resolved formal invalidates revalidation. Exact observed joins supplement executable identity because ST annotations and DU edges are not fully represented by a bare tree key. Token checks precede all native dereferences, including after scope closure. Copied records remain readable after expiry but have no transformation authority.

These facts do **not** prove affine dependence, no conflicts between threads, prefill/decode, allocator or cache generations, inter-call lifetime, concurrent reader safety, cache publication, HBM hits, cacheline reuse or cross-head reuse eligibility. Neither `Q=1`, a packed type nor source quantization proves a serving phase. Missing information remains unknown. Quantized candidates remain disabled.

## COMMENT and two-phase search preservation

High construction still emits the original semantic COMMENTs. Because general PREOPT COMMENT retention is a separately deferred effort, Q1 restores source-stage explanations at function entry from validated program metadata and surviving operation joins. This location avoids the current SIMD loop-body assumption that statements have expression children. The explanations preserve byte promotion, strict ordered arithmetic, guard/status behavior, fresh updates, partial-result refusal and invocation-local cache/scale limits. Per-operation comments name the surviving source-stage join; they do not assert that an eliminated/fused schedule still exists. The existing whirl2c emitter prints these WHIRL COMMENT nodes into actual generated C. No general WOPT COMMENT behavior changes.

This integration captures a fixed semantic algorithm and invalidates/rebuilds its analyses. It does not add an exploration path that creates WN/ST/TY, compile each candidate, profile in search, or lower multiple alternatives. Existing estimation-only portfolios, convergence controls, global budgets, models and selected-plan legality/atomic application remain intact. Any later quantized optimization must independently pass its serving/dependence/realization gates, select one legal plan, apply it, invalidate/rebuild facts, then run correctness tests. AOT remains the baseline.

## Validation and remaining risks

`osprey/be/lno/tests/run_quantized_production_review.py` drives original native source images through the actual backend. Its fixed matrix includes all ten fixtures at O3, a dense representative at O0/O1/O2, trace-off parity and PREOPT-only processing. Each retained High, post-PREOPT and final scalar image is independently reopened, converted by whirl2c, compiled and executed against eager source and the independent expanded reference. Checks include exact cache bytes/scales, attention/LSE tolerances, signed decoder extremes/all nibbles, round-to-nearest-even half ties, invalid pages and integer overflow, negative indices, duplicate updates, nonfinite encoders, buffer canaries and immutable inputs. Rebinding reports fresh actual sites, old-token expiry and unchanged native tables. Default/off, invalid ABI and unsafe numerics exercise ordinary fallback before any Q1 checkpoint.

Additional native corruption tests reopen real PREOPT images, discard every COMMENT, check unchanged operation joins, reject changed valid/empty tags and stale scale/alias/program seals, exercise metadata parse failures and scope/epoch expiry, and preserve before/after native corruption images with raw diffs. Missing all operation tags yields unknown groups, never invented proof. Legacy short/long recipes, full ST/TY/source traces and typed executable identities are compared; refusal routes must give identical ordinary backend output. Existing estimation-only/selected-reference tests and control/movement tests remain required. Audit added undefined symbols against the previous retained `be.so`; only libc/libstdc++ runtime imports are expected, with unchanged NEEDED entries, no Builder/JsonCpp/Python boundary leak, and successful lw_inline consumer closure.

Default x86 SIMD compilation is checked separately. Its final native vector IR includes constructs such as REPLICATE that the existing whirl2c host-C emitter cannot compile; executable final-output oracles therefore use `-LNO:simd=0`. This does not certify native SIMD execution. The High and PREOPT boundaries remain scalar and executable. There is no GPU execution or Hopper performance evidence. This milestone does not deliver a production serving adapter or asynchronous quantized pipeline. Checkpoint fork/metadata overhead is compile-time only; serving scratch allocation and coarse scalar semantic expansion remain costs to address in later selected realization.

Focused qualification passes 15 scalar backend configurations, compiling and executing 45 emitted host libraries and checking 270 base returned values against both references, plus boundary/refusal inputs. The ten O3 cases rebind 767 storage roots and 1761 static memory sites, including 37 conservative indirect sites. Seven legacy/native/search tests and 181 standalone control/movement assertions pass. Two real PREOPT-image corruption tests pass, with 153 and 246 sites explicitly unknown when operation tags are removed. Legacy full traces/typed keys and trace-off output agree exactly. Default SIMD compilation without checkpoints passes separately. The backend audit records 11 additional standard runtime imports and unchanged five NEEDED libraries; no frontend-builder/JsonCpp/Python import is added. lw_inline links and loads successfully. Final-path replay and source/tool/command hashes are retained under the new `mla-q1-production-routing-rebinding` receipt family; earlier receipts are unchanged.
